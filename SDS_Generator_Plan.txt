OVERVIEW
--------
Build a modular Safety Data Sheet (SDS) PDF generation engine that mirrors the
existing TDS Generator's ReportLab Platypus architecture. Key design principle:
SDS requires FULL ingredient transparency (CAS numbers + concentrations fully
disclosed). This is the opposite of the TDS which hides them via _filter_components().

Same ReportLab primitives will be reused verbatim:
  - _section_bar(), _two_col_table(), _hex(), _esc()
  - _logo_cell(), _logo_width()
  - BaseDocTemplate + Frame + PageTemplate + onPage footer pattern
  - BrandConfig system (brand_config.py copied from TDS Generator)

FILE 1: sds_data_model.py — THE SHARED BRAIN
================================================================================

All dataclasses use field(default_factory=...) for mutable defaults.
Pattern mirrors data_model.py from TDS Generator exactly.

DATACLASSES:

SDSIngredient
  name: str
  cas_number: str
  wt_percent_low: float       <- split floats (not "20-25%" string)
  wt_percent_high: float         enables classifier threshold comparisons
  function: str
  trade_secret: bool = False

GHSHazardCategory             <- one classified hazard
  class_name: str             "Oxidizing liquids"
  category: str               "2" or "1A" (string, not int)
  h_codes: list[str]
  p_codes: list[str]
  pictogram_codes: list[str]

GHSClassification             <- aggregated classifier output
  signal_word: str
  categories: list[GHSHazardCategory]
  pictograms_needed: list[str]    (deduplicated)
  all_h_statements: list[str]     (ordered by code number)
  all_p_statements: list[str]     (grouped P2xx / P3xx / P4xx / P5xx)

OELEntry                      <- one row of Section 8 OEL table
  substance_name: str
  cas: str
  authority: str              "ACGIH" | "NIOSH" | "OSHA" | "CA"
  oel_type: str               "TWA" | "STEL" | "IDLH" | "Ceiling" | "TWA-PEL"
  value: str                  string preserves ">" prefix
  unit: str                   "ppm" | "mg/m³"

ToxicologyRecord              <- one row of Section 11 LD50/LC50 table
  substance: str
  route: str                  "Oral" | "Dermal" | "Inhalation ATE"
  species: str
  result: str                 "LD50 Rat: 693.7 mg/kg"

AquaticToxRecord              <- one row of Section 12 aquatic table
  substance: str
  organism_type: str          "Fish" | "Aquatic Invertebrates" | "Aquatic Plants"
  organism: str               "Pimephales promelas"
  metric: str                 "LC50" | "EC50" | "NOEC"
  value: str                  "16.4 mg/L"
  endpoint: str               "mortality" | "growth rate"

TransportInfo                 <- one record per transport mode
  mode: str                   "DOT" | "IMDG" | "IATA"
  un_number: str
  proper_shipping_name: str
  hazard_class: str
  packing_group: str
  labels_required: str
  environmental_hazard: str
  special_precautions: str

RegulatoryListing             <- one row of Section 15 regulatory table
  substance_name: str
  cas: str
  tsca_listed: bool
  sara_302: bool
  sara_313: bool
  cercla_listed: bool
  cercla_rq_lbs: str          "1000" or ""
  rcra_code: str
  caa_112r: bool
  prop_65: bool
  prop_65_warning: str
  rtk_states: list[str]       ["MA", "NJ", "NY", "PA"]

ManufacturerInfo
  company_name: str
  address_line1: str
  city_state_zip: str
  country: str
  phone: str
  website: str
  email: str
  emergency_phone: str
  emergency_provider: str     "CHEMTREC"
  emergency_account: str

SDSPhysicalProperties         <- extends TDS version with all SDS-required fields
  appearance, odour, odour_threshold, pH, melting_point, boiling_point,
  flash_point, evaporation_rate, flammability, upper_explosive_limit,
  lower_explosive_limit, vapour_pressure, vapour_density, density,
  relative_density, solubility, partition_coefficient, auto_ignition_temp,
  decomposition_temp, viscosity

SDSProduct                    <- MASTER OBJECT (fields organised by SDS section)
  Section 1:  product_name, product_code, product_type, manufacturer,
              recommended_use, restrictions_on_use
  Section 2:  classification (GHSClassification), label_notes
  Section 3:  ingredients (list[SDSIngredient]), additional_ingredient_info
  Section 4:  first_aid_inhalation, first_aid_skin, first_aid_eye,
              first_aid_ingestion, first_aid_general, first_aid_symptoms,
              first_aid_doctor_notes
  Section 5:  extinguishing_media, unsuitable_extinguishing_media,
              firefighting_hazards, firefighting_ppe, firefighting_precautions
  Section 6:  spill_personal_precautions, spill_environmental_precautions,
              spill_containment_cleanup
  Section 7:  handling_precautions, storage_conditions, specific_end_use
  Section 8:  control_parameters (list[OELEntry]), engineering_controls,
              ppe_respiratory, ppe_hand, ppe_eye, ppe_skin, hygienic_measures
  Section 9:  physical_properties (SDSPhysicalProperties)
  Section 10: reactivity, chemical_stability, hazardous_reactions,
              conditions_to_avoid, incompatible_materials, hazardous_decomposition
  Section 11: toxicology_records, skin_corrosion_result, eye_damage_result,
              sensitisation, mutagenicity, carcinogenicity_iarc, carcinogenicity_ntp,
              reproductive_toxicity, stot_single, stot_repeated, aspiration_hazard
  Section 12: aquatic_tox_records, chronic_tox_records,
              persistence_degradability (list[tuple[str,str]]),
              bioaccumulation, mobility, pbt_vpvb, other_adverse_effects
  Section 13: disposal_methods, disposal_container
  Section 14: transport (list[TransportInfo])
  Section 15: regulatory_listings (list[RegulatoryListing]),
              tsca_inventory, prop_65_warning_text
  Section 16: prepared_by, preparation_date, revision_date, revision_number,
              supersedes, disclaimer, nfpa_ratings, hmis_ratings, abbreviations

SDSDocument
  product: SDSProduct
  version: str = "1.0"
  preparation_date: str

Also include dict_to_sds_product(d: dict) -> SDSProduct using the same
safe-conversion pattern as dict_to_product() in TDS data_model.py.

CLASSIFY ALGORITHM:

  def classify(self, ingredients: list[SDSIngredient]) -> GHSClassification:
      triggered = {}  # hazard_class -> (worst_category, trigger_ingredient_name)

      for ing in ingredients:
          conc = ing.wt_percent_high   # USE UPPER BOUND (conservative / safety-correct)
          rec = self._db.get(ing.cas_number.strip())
          if not rec:
              continue
          for hazard_class, trigger in rec["ghs_triggers"].items():
              if conc >= trigger["threshold_pct"]:
                  cat = str(trigger["category"])
                  if (hazard_class not in triggered or
                          self._is_more_severe(cat, triggered[hazard_class][0])):
                      triggered[hazard_class] = (cat, ing.name)

      categories = self._build_categories(triggered)
      signal_word = self._determine_signal_word(triggered)
      pictograms = sorted({c for cat in categories for c in cat.pictogram_codes})
      h_stmts = self._collect_h_statements(categories)
      p_stmts = self._collect_p_statements(triggered)

      return GHSClassification(
          signal_word=signal_word,
          categories=categories,
          pictograms_needed=pictograms,
          all_h_statements=h_stmts,
          all_p_statements=p_stmts,
      )

SIGNAL WORD RULE:
  DANGER  if any Cat 1 (any suffix), Cat 2 oxidizing liquid, Cat 2 acute toxicity
  WARNING if only Cat 3-4 STOT or Cat 3-4 acute toxicity
  DANGER beats WARNING when both apply

FILE 4: sds_generator.py — MAIN ORCHESTRATOR
================================================================================

CLASS: SDSGenerator

  __init__(self, db_path, api_config_path):
    - Load raw_material_db.json -> dict keyed by CAS string
    - Load Anthropic client from api_config.json (same key as TDS Generator)
    - Instantiate GHSClassifier(db)

  generate(self, product: SDSProduct) -> SDSDocument:
    1. product.classification = self._classifier.classify(product.ingredients)
    2. self._enrich_from_db(product)
    3. self._generate_first_aid(product)      <- Claude API call
    4. self._generate_firefighting(product)   <- Claude API call
    5. if not product.transport:
         product.transport = self._build_transport(product)
    6. product.generated_date = date.today().isoformat()
    7. return SDSDocument(product=product)

  _enrich_from_db(self, product):
    For each ingredient, lookup DB record and populate:
    - product.control_parameters  (OELEntry list — extend, no duplicates by key)
    - product.toxicology_records  (ToxicologyRecord list)
    - product.aquatic_tox_records / chronic_tox_records
    - product.regulatory_listings (RegulatoryListing list)
    - product.skin_corrosion_result, eye_damage_result, stot_single
    - product.carcinogenicity_iarc, carcinogenicity_ntp (strings)
    - product.persistence_degradability, bioaccumulation, mobility lists

  _generate_first_aid(self, product):
    Claude API call:
    - System: "You are a GHS-compliant SDS technical writer..."
    - User: JSON with product_name, classification (signal word + H-codes), ingredient names
    - Response: structured JSON with inhalation, skin, eye, ingestion,
                general_notes, doctor_notes fields
    - Use ephemeral cache_control on system prompt (same pattern as TDS Generator)
    - temperature=0 for deterministic output

  _generate_firefighting(self, product):
    Similar Claude API call -> extinguishing_media, unsuitable_media,
                               hazards, ppe, precautions fields

  _build_transport(self, product) -> list[TransportInfo]:
    Rule-based (no API needed):
    - Peracetic acid + oxidizing liquid classified -> UN3139
    - DOT: UN3139, "Oxidizing liquid (Hydrogen peroxide, Nitric acid)", 5.1(8), PG II
    - IMDG: same UN3139 with marine pollutant note (Peroxyacetic acid)
    - IATA: Not regulated (per gold standard)

FACTORY FUNCTION: sds_from_oxystrike() -> SDSProduct
  Pre-populate OxyStrike CC1383 for testing without API calls:
  - 5 SDSIngredient objects with exact OxyStrike concentrations from Section 3
  - ManufacturerInfo for Capacity Chemical LLC (from Section 1)
  - SDSPhysicalProperties from Section 9 of gold standard:
      appearance="Clear and colorless"
      odour="Pungent, Strong vinegar-like"
      pH="< 2"
      density="1.169"
  - Section 10 text from gold standard
  - classification left as GHSClassification() (populated by generate())

================================================================================
KEY DESIGN DECISIONS
================================================================================

1. CONCENTRATION AS FLOATS NOT STRINGS
   SDSIngredient uses wt_percent_low: float and wt_percent_high: float.
   This enables direct threshold comparison in the classifier (conc >= 8.0)
   without regex parsing. The PDF builder formats these as "20–25%" when rendering.

2. CONSERVATIVE CLASSIFICATION (upper bound)
   GHSClassifier always uses ing.wt_percent_high for threshold comparisons.
   This is the regulatory-correct approach for worst-case safety assessment.

3. NO PAGEBREAK INSERTIONS
   The 16 sections are dense enough that natural ReportLab flow handles
   pagination. KeepTogether() wrappers prevent orphaned section headers.

4. DB-SOURCED OEL / TOXICOLOGY / REGULATORY DATA
   All numerical data (LD50, OELs, regulatory flags) comes from raw_material_db.json,
   not from Claude API. Claude is only used for narrative text (first aid language,
   firefighting instructions). This ensures data accuracy and auditability.

5. SAME BRAND SYSTEM
   BrandConfig is shared with TDS Generator (copied verbatim). Both systems
   produce PDFs with the same Capacity Chemical branding. Path resolution in
   brand_config.py uses Path(__file__).parent, which correctly resolves to
   the SDS Generator directory after copying.

6. PICTOGRAM RENDERING
   Primary: PNG files from assets/pictograms/ (GHS03.png, GHS05.png, GHS07.png)
   Fallback: Programmatic ReportLab Drawing with diamond Polygon geometry
   The fallback ensures the PDF renders correctly even without asset files.

7. FULL REGULATORY TRANSPARENCY (LEGAL REQUIREMENT)
   Section 3 shows all CAS numbers and concentration ranges with NO filtering.
   Section 15 lists all applicable federal and state regulatory citations.
   This is non-negotiable for OSHA HCS 2012 compliance.
